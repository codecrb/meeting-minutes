# meeting-minutes

一个用于生成统一风格会议记录的 Claude Code Skill。

## 功能

将会议的原始文字记录（语音转文字、粗糙笔记、对话记录等）整理成规范的 Markdown 格式会议记录，包含三个固定部分：

1. **会议基本信息**：会议名称、主题、时间、形式（线上/线下）、参与人员、主持人、记录人
2. **专家和领导意见**：逐人整理发言要点，口语转书面
3. **会议总结**：汇总合并相似意见，形成会议共识和行动建议

## 特性

- 区分线上/线下会议：线上记录平台和会议号，线下记录地点
- 区分讨论类和汇报类会议，自动调整第一节写法
- 自动识别并排除记录人/工作人员，只整理专家/领导意见
- 缺失信息标注"（待确认）"，不推断不编造

## 安装

### 方式一：直接复制

将 `meeting-minutes/` 文件夹复制到你的 Claude Skills 目录：

```bash
# macOS / Linux
cp -r meeting-minutes/ ~/.claude/skills/

# Windows
xcopy /E meeting-minutes\ %USERPROFILE%\.claude\skills\meeting-minutes\
```

### 方式二：通过 .skill 包安装

如果有 `.skill` 文件，在 Claude Code 中运行：

```
/install-skill meeting-minutes.skill
```

## 使用方法

在 Claude Code 中，直接粘贴会议原始文字并要求整理即可触发此 skill：

```
帮我整理一下这次会议记录：

[粘贴你的会议文字内容]
```

## 输入格式

支持各种格式的原始文本：
- 语音识别/转写文字
- 手写笔记的文字版
- 会议群聊记录整理
- 已有的非结构化会议摘要
